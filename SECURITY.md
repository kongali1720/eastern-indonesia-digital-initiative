# Security Policy

## Reporting a Vulnerability

Please do not publish credentials, private keys, personal information,
or exploitable vulnerability details in public issues.

Use a private contact channel maintained by the project owner to report
security concerns. Confirm the appropriate contact channel before sending
sensitive information.

Include the affected component, impact, reproduction steps, and any
suggested mitigation, while avoiding access to data or systems you do
not own or have permission to test.

## Scope

This repository contains project documentation and planning materials.
A published document does not imply that a system is deployed, operational,
or authorized for security testing.
